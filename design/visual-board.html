百灵鸟在五线谱上飞行 · 视觉设计样板

墨蓝天穹里的一张发光总谱。夜色的冷蓝是纸与天空，琥珀金的乐音是百灵鸟的羽光；五根垂直轨道即旋转 90° 的五线谱五根谱线，音符是骑在线上坠落的符头，判定线是乐谱上的指挥线。

03　音符造型（同形状不同色 · 3 种节奏型变体）

标准 note

符头 path：M-23,0 C-23,-11 -12,-18 2,-16 C16,-14 23,-6 23,2 C23,12 12,18 -2,16 C-16,14 -23,9 -23,0 Z，旋转 -20°，骑在谱线腰线上；符干 26px；左上玻璃高光。

强音 accent

符干顶端向左弯出小旗，旗色 = 轨道色提亮 15%。强音音符外发光 blur 提升到 10px。

长音 hold

符头 + 6px 竖直光带（轨道色 40% → 透明），判定线处加小方块锁扣。

材质三层：① 135° 线性渐变（轨道色 → 提亮 22% → 压暗 12%）② 左上玻璃高光椭圆 rgba(255,255,255,.55) ③ 外发光副本 blur 6px 加色混合。下半部保留 1px 深色描边，保证在爆闪时仍有轮廓。

04　命中特效分级（形状必须可辨）

PERFECT

12 芒星 + 2 圈涟漪 + 8 片羽毛 + 判定线白闪 60ms。文字 22/800 白金 + 2px 白描边，**判定线下方 judgeY+60**，上飘 24px / 360ms；`+120` 同基线右偏 56px。

GOOD

8 芒星 + 1 圈涟漪 + 4 片小羽毛。文字 18/600 青 + 深色投影，**判定线下方 judgeY+60**，上飘 18px / 300ms。

MISS

无爆闪。音符碎裂成 7 片灰色碎屑下坠；判定线该轨道段玫红横条闪 2 次（140ms）。文字 18/600 玫红，**判定线下方 judgeY+60**，上飘 12px / 280ms。

05　Combo 里程碑四档

10 COMBO　屏震 4px / 180ms

取消独立横幅 ——「10」本身就是屏幕上最大的 Combo 数字。改为：Combo 数字加 4px 金色 glow 并 scale 1→1.15→1；判定线本体加亮（不改几何）；12 片羽毛只在判定线处上飘。

30 COMBO　屏震 7px / 350ms

金色扁环（rx 0→560 / ry 0→26，1.2px，opacity ≤.28，可穿透）+ 四角金色内阴影 + 判定线只加亮**不位移**；「30 / CHAIN」落在里程碑带右段 x900–1160。

50 COMBO　屏震 9px / 500ms

羽毛风暴 24 片自 y=800 上飘，到 judgeY−40 处触发涟漪后消失（不在通道内持续飘过）；判定线只加亮**不加几何**；分数 scale 1→1.12→1。「50 / CHAIN」落在里程碑带左段 x40–300。

100 COMBO　屏震 12px / 1.2s　完美通关

全屏白闪 #FFF8E7 + 5 束短光柱（每轨向上 160px，260ms 衰减）+ 羽毛向上喷发 120 片 + 横幅徽章 x380–820（y judgeY+100~+156，Combo 数字让位）。

08　反例清单（出现即判为不精致）

音符与谱面

① 纯色方块音符，无符头造型 / 渐变 / 高光
② 音符色与背景近似（深蓝音符落深蓝底）
③ 5 轨做成红黄绿蓝紫高饱和等差色环
④ 水平五线谱去对应垂直轨道（除非背景网格且 α≤.18）
⑤ 判定线仅 1px 实线，无落点垫无辉光
⑥ 判定窗口 ±30 / ±65 完全不可见
⑦ 音符穿过判定线不消失或消失太晚
⑧ 音符在 y=-50 硬出现，无渐隐入场
⑨ 小节线与音符不同速，时间感崩塌

反馈 · 排版 · 质感

⑩ 命中无任何反馈（按键无光柱 / 轨道高亮）
⑪ 每次命中都震屏
⑫ 粒子用圆形白光点 200 个（丢掉羽毛识别点）
⑬ GOOD 与 MISS 仅靠颜色区分，无形状差异
⑭ 里程碑特效被音符盖住（层级错）
⑮ 赛博朋克紫粉渐变模板
⑯ 默认系统字体做 HUD 分数
⑰ 变动数字未用 tabular-nums
⑱ 灰底 + 白线 / 纯黑背景
⑲ 默认 alert / confirm / select 做覆盖层
⑳ 音符逐个挂 SVG feGaussianBlur → 掉帧
㉑ 反馈文字画在轨道轴上贴近判定线 → 被本轨下一音穿过
㉒ 里程碑横幅/徽章横跨下落通道 → 遮住要打的音符
㉓ 判定线在游戏中位移、变宽、变双线 → 参照系被改，判定随机
㉔ 落点垫按下时改尺寸 → 误判 PERFECT 窗口边界
㉕ MISS 玫红挪用到 Combo / 菜单 → 语义串味
㉖ 只用颜色区分 5 轨 → 色觉差异玩家无法识别
㉗ 底部坐标硬编码 560 → 移动端 judgeY=620 整体错位

09　SVG / Canvas 分工

L0 背景 · SVG + CSS（静态）

多层渐变、纸纹 feTurbulence、星尘、5 条垂直谱线、谱表边界、背景水平细网格、谱号与拍号、唱名、图标。滤镜声明一次即复用，可无损缩放，可挂无障碍语义。

L1 谱面 + L2 特效 · Canvas 2D（每帧）

音符（sprite drawImage）、拖尾、落点垫、节拍线 / 小节线、判定线、爆闪、涟漪、粒子、里程碑光环、全屏闪白。L2 用 globalCompositeOperation='lighter' / 'screen'。禁止每帧 createLinearGradient / shadowBlur。

L3 HUD · DOM + CSS

分数、Combo、进度条、评级徽章、反馈文字、开始 / 暂停 / 结算三层覆盖层。事件驱动更新，不参与逐帧重绘。逻辑坐标恒为 1200×800，外层 transform: scale() 适配。

性能硬指标：60fps（120Hz 屏 ≥50fps），主线程单帧 ≤8ms；粒子池上限 400；音符 sprite 预渲染 5 色 × 3 变体 = 15 张；屏震期间不降粒子数。
